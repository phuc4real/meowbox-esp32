# MeowBox REST API (v1)

Contract between the web UI (`web/src/`) and the firmware (`components/net/`).
The mock in `web/mock_server.py` implements exactly this document.

## General rules

- Transport: plain HTTP on port 80 (`http://meowbox.local` or the device IP). JSON bodies are UTF-8,
  `Content-Type: application/json`. Request bodies are at most **8 KB**, except `/api/ota` and
  `/api/notify/audio`.
- Shapes are kept flat and short so the firmware can parse them with cJSON. Booleans are JSON `true`/`false`.
  Unknown fields are ignored, and a missing field in a `PUT` keeps its current value.
- Success: HTTP 200 with a JSON object (`{"ok":true}` when there is nothing else to return).
- Error: HTTP 4xx/5xx with `{"err":"<code>"}`. Codes: `auth` (401), `forbidden` (403), `bad_json` (400),
  `bad_value` (400), `not_found` (404), `too_large` (413), `too_many` (429), `busy` (503), `bad_image` (400),
  `bad_old` (403), `queue_full` (429).
- Times are Unix seconds (UTC). The device always uses the `ICT-7` time zone; the UI shows local times in ICT.

### Static files

| Path | File in LittleFS | Headers |
|---|---|---|
| `/`, `/index.html` | `/web/index.html.gz` | `Content-Type: text/html; charset=utf-8`, `Content-Encoding: gzip` |
| `/app.css` | `/web/app.css.gz` | `text/css`, gzip |
| `/themes.css` | `/web/themes.css.gz` | `text/css`, gzip (generated by `tools/gen_themes.py`) |
| `/app.js` | `/web/app.js.gz` | `application/javascript`, gzip |
| `/fonts/<file>` | `/web/fonts/<file>` (not gzipped) | `.woff2` → `font/woff2`, `fonts.json` → `application/json`. `Cache-Control: max-age=86400` is fine |
| `/themes/<id>.png` | `/web/themes/<id>.png` | `image/png`. Missing → `404`; the UI then draws a placeholder in that theme's colours |

`/fonts/fonts.json` maps each font file to its `@font-face` data:
`{"archivo-vi.woff2":{"family":"Archivo","weight":"400 800","style":"normal","stretch":"62% 100%"}, ...}`.
The UI loads only the files listed in the active theme's `fonts` (a listed name such as `chakra-petch-vi.woff2` that
is not in `fonts.json` also matches its variants `chakra-petch-400-vi.woff2`, ...). No `fonts.json` or files → the
system font stacks from `themes.css`. Nothing is ever loaded from a CDN (SoftAP mode has no internet).

Static files need no auth (the login screen is part of the app). `Cache-Control: no-cache` is recommended
so an OTA'd web bundle is picked up. In SoftAP mode any unknown path redirects to `/` (captive portal).

### Authentication

| Path | Auth |
|---|---|
| `POST /api/login`, `GET /api/theme` | none |
| `/api/notify`, `/api/notify/audio`, `/api/notify/history` | **Bearer token** (`Authorization: Bearer <token>`), or `?token=<token>` on GET. The session cookie is also accepted so the web UI can use them. |
| every other `/api/*` | **session cookie** `sid` |

- Default credentials `meowbox` / `m3owb0x2026`. The password is stored as SHA-256(salt + password) in `/data/auth.json`.
  A device still on the pre-2026-11-23 default (`meowbox`) is moved to the new default on boot.
- Sessions: random 128-bit id, max 4 at a time (oldest dropped), expire after 24 h without use. Kept in RAM,
  so a reboot logs everyone out.
- 5 failed logins in a row → `429 too_many` for 30 s.
- Missing or invalid session → `401 {"err":"auth"}`; the UI then shows the login screen.

## Session

### `POST /api/login`
```json
{"user":"meowbox","pass":"m3owb0x2026"}
```
→ `200`, `Set-Cookie: sid=9f2c...e1; Path=/; HttpOnly; SameSite=Strict`
```json
{"ok":true,"def_pw":true}
```
`def_pw` is true while the default password is still in use (the UI shows a banner). Wrong credentials → `401 {"err":"auth"}`.

### `POST /api/logout`
Body `{}`. Drops the session, clears the cookie. → `{"ok":true}`

### `GET /api/session`
→ `{"user":"meowbox","def_pw":true}` or `401`. Used by the UI at startup.

### `POST /api/password`
```json
{"old":"m3owb0x2026","new":"m30w-secret"}
```
`new` must be 6–32 characters. → `{"ok":true}`. Wrong `old` → `403 {"err":"bad_old"}`; bad length → `400 bad_value`.
All other sessions are invalidated.

## Status

### `GET /api/status`
```json
{
  "ver":"0.1.0","build":"2026-11-20 21:04","up":93784,
  "mode":"sta","ssid":"NhaMeo","ip":"192.168.1.50","rssi":-58,
  "bat":78,"chg":true,"usb":true,
  "heap":142336,"heap_min":98304,"psram":6815744,"psram_tot":8388608,
  "time":1763791200,"vol":40,"sleep":0,"pc":true,"def_pw":true,
  "play":{"st":"play","id":2,"name":"Lofi Girl","title":"Snowman - Kudasai"}
}
```
- `mode`: `sta` (connected), `ap` (SoftAP portal `MeowBox-XXXX`, WPA2, password `meowbox2026`), `conn` (connecting).
- `bat`: 0–100 or `-1` if unknown. `chg`: charging; `usb`: USB power present.
- `heap`/`heap_min`: free internal heap now/minimum since boot (bytes). `psram`/`psram_tot`: free/total PSRAM.
- `sleep`: seconds left on the sleep timer, 0 = off. `pc`: PC agent connected.
- `play.st`: `stop` | `buf` (connecting/buffering) | `play` | `err`. `id` is the station id, or 0 for an ad-hoc URL.
  `title` is the ICY StreamTitle (may be empty).

## Wi-Fi

### `GET /api/config/wifi`
```json
{"cur":"NhaMeo","max":5,"nets":[{"ssid":"NhaMeo"},{"ssid":"VanPhong"}]}
```
Passwords are never returned. Order = connect priority.

### `PUT /api/config/wifi`
```json
{"nets":[{"ssid":"VanPhong"},{"ssid":"NhaMeo"},{"ssid":"Moi","pass":"12345678"}]}
```
Replaces the saved list (reorder/delete). An entry without `pass` keeps the stored password for that SSID;
a new SSID needs `pass` (empty string = open network). At most `max` entries. → same shape as GET.

### `GET /api/wifi/scan`
Blocking scan (~2–3 s). → sorted by RSSI, deduplicated by SSID:
```json
{"aps":[{"ssid":"NhaMeo","rssi":-52,"ch":6,"sec":true},{"ssid":"Cafe Free","rssi":-80,"ch":11,"sec":false}]}
```
`503 busy` if a scan is already running.

### `POST /api/wifi/connect`
```json
{"ssid":"NhaMeo","pass":"12345678"}
```
Saves the network at the top of the list and switches to it. → `{"ok":true}` is sent **before** switching;
the device may get a new IP (shown on its screen). Omit `pass` to reuse a saved password.

## Radio

### `GET /api/config/radio`
```json
{
  "vol":40,"last":2,"max":50,
  "st":[
    {"id":1,"name":"VOV3","url":"https://str.vov.gov.vn/vovlive/vov3.sdp_aac/playlist.m3u8","type":"hls"},
    {"id":2,"name":"Lofi Girl","url":"https://www.youtube.com/watch?v=jfKfPfyJRdk","type":"youtube"},
    {"id":3,"name":"Radio Paradise","url":"http://stream.radioparadise.com/mp3-128","type":"stream"}
  ]
}
```
- `type`: `stream` (MP3/AAC over HTTP/HTTPS, incl. `.pls`/`.m3u` already resolved), `hls` (`.m3u8`),
  `youtube` (`url` is the YouTube link; the firmware plays `http://<relay>/yt/stream?url=<urlencoded>` via the PC agent; `<relay>` comes from the agent's `hello` message on `/ws/pc` (`auto:true`) or from `host:port`).
- `id`: integer 1–65535, unique, stable (alarms reference it). New stations from the UI get `max(id)+1`.
- Array order = display order. `name` ≤ 48 bytes, `url` ≤ 256 bytes.

### `PUT /api/config/radio`
`{"st":[...]}` (full list, same item shape) and/or `{"vol":40}`. → same shape as GET.
Alarms that reference a deleted station fall back to `chime`.

### `POST /api/radio/play`
One command per call:
```json
{"cmd":"play","id":3}
{"cmd":"play"}
{"cmd":"play","url":"http://ice.example/live.mp3","name":"Thử đài"}
{"cmd":"stop"}
{"cmd":"next"}
{"cmd":"prev"}
{"cmd":"vol","vol":55}
```
`{"cmd":"play"}` without `id`/`url` resumes the last station (`last`). `play` with `url` is a preview of a search result (not saved, `play.id` = 0). `vol` 0–100.
→ `{"ok":true,"vol":55,"play":{...same as status.play...}}`. Unknown id → `404 not_found`.

### `GET /api/sleep`
→ `{"left":1200}` (seconds, 0 = off)

### `POST /api/sleep`
`{"min":30}` (one of 15/30/60/90 or any 1–240; `0` cancels). Stops the radio when it reaches 0. → `{"left":1800}`

## Alarms

### `GET /api/config/alarms`
```json
{"snooze":5,"max":5,"al":[
  {"on":true,"h":6,"m":30,"days":31,"snd":"chime","st":0},
  {"on":false,"h":8,"m":0,"days":96,"snd":"radio","st":3}
]}
```
- `days`: bitmask, bit0 = Monday … bit6 = Sunday (31 = Mon–Fri, 96 = Sat+Sun, 127 = every day, 0 = once).
- `snd`: `chime` | `radio`. With `radio`, `st` is the station id; if the stream fails, the chime plays.
- `snooze`: minutes (1–30). At most `max` alarms.

### `PUT /api/config/alarms`
Same shape (full `al` list). → same shape as GET.

## Weather

### `GET /api/config/weather`
```json
{"on":true,"name":"Hà Nội","lat":21.0245,"lon":105.8412,"unit":"c",
 "now":{"t":24.5,"code":3,"hi":28,"lo":20,"at":1763790000}}
```
`now` is read-only (last open-meteo result, `null` if none yet). `code` = WMO weather code. `unit`: `c` | `f`.
The UI looks the city up itself at `https://geocoding-api.open-meteo.com/v1/search` and only sends the result.

### `PUT /api/config/weather`
`{"on":true,"name":"Đà Nẵng","lat":16.068,"lon":108.212,"unit":"c"}` → same shape as GET (the device refreshes now).

## Display

### `GET /api/config/display`
```json
{"bri":80,"idle_bri":20,"idle_s":60,"h24":true,
 "night":true,"night_mode":"auto","n_from":22,"n_to":7,"n_bri":5,
 "lang":"vi","tz":"ICT-7","theme":"swiss","fx":"full"}
```
- `bri`, `idle_bri`, `n_bri`: 0–100. `idle_s`: dim after this many seconds without touch (0 = never).
- `theme`: id of a theme from `GET /api/themes`. Default **`"swiss"`**, factory reset → `"swiss"`. Unknown id → `400 bad_value`.
  The speaker rebuilds its screens with the new theme at once. Stored in NVS group `display`, key `theme`.
- `night_mode`: `auto` (default: night from hour `n_from` to `n_to`, 0–23, may wrap midnight) | `on` (always) | `off`.
  Night uses the active theme's own night variant.
- `night`: legacy bool, mirrors `night_mode != "off"`. A PUT with only `night` maps `true` → `auto`, `false` → `off`;
  when both are sent, `night_mode` wins.
- `fx`: `full` (the theme's minimal effects) | `eco` (no RGB split, scanlines or tilted blocks; also switched on by
  itself on battery). The web page applies the same setting to itself (`data-fx` on `<html>`).
- `lang`: device screen language `vi` | `en`. `tz` is read-only (always `ICT-7`).

### `PUT /api/config/display`
Same shape (without `tz`), any subset, e.g. `{"theme":"zen"}`. Applied immediately. → same shape as GET.

### `GET /api/themes`
Session auth. Theme list for **Settings → Appearance**; the web builds its cards from it, so a new theme needs no web change.
```json
{"themes":[
  {"id":"swiss","name":{"vi":"Swiss","en":"Swiss"},"desc":{"vi":"Tối giản kiểu Thuỵ Sĩ, dễ đọc","en":"Minimal Swiss style, easy to read"},
   "default":true,"preview":"/themes/swiss.png","fonts":["archivo-vi.woff2"]},
  {"id":"brutal","name":{"vi":"Brutalism","en":"Brutalism"},"desc":{"vi":"…","en":"…"},
   "default":false,"preview":"/themes/brutal.png","fonts":[]}
 ],"current":"swiss"}
```
Order = display order. `fonts` = web font files in `/fonts/` used by that theme. The same data is in `web/themes.json`
(written by `tools/gen_themes.py`).

### `GET /api/theme`
**No auth**, so the login page is already themed. → `{"theme":"swiss","fonts":["archivo-vi.woff2"]}`
(`fonts` optional; without it the page loads the fonts after login).

### `GET /api/screenshot`
Session auth. The current screen as an uncompressed **BMP** (296×240, 16- or 24-bit), `Content-Type: image/bmp`,
`Cache-Control: no-store`. Optional `?tile=N` (0–4) renders that tile instead of the visible one. The Overview page
shows it, refreshing every 5 s while the tab is visible; on `404` it shows a placeholder.

## Cat

### `GET /api/config/cat`
```json
{"name":"Mướp","fur":"tabby","diff":"normal",
 "stats":{"age":12,"stage":"kitten","full":80,"fun":65,"clean":90,"energy":55,"health":100,"mood":"happy","away":false}}
```
- `fur`: `tabby` (mướp) | `black` | `white` | `calico` (tam thể) | `gray`.
- `diff`: `easy` | `normal` | `hard`.
- `stats` is read-only: `age` in days, `stage` = `kitten` | `junior` | `adult` | `senior`, values 0–100,
  `mood` = `happy` | `sad` | `hungry` | `sick` | `sleep`, `away` = the cat left (needs reset).

### `PUT /api/config/cat`
`{"name":"Mun","fur":"black","diff":"easy"}` (`name` ≤ 16 bytes) → same shape as GET.

### `POST /api/cat/reset`
Body `{}`. Starts a new kitten (keeps name/fur/diff). → same shape as GET.

## Notifications

### `GET /api/config/notify`
```json
{"token":"q7Lw2xK9pR4tY8vZ","dur":10,"vol":70,"quiet_low":true,"ntfy":""}
```
- `token`: 16 chars `[A-Za-z0-9]`, generated at first boot.
- `dur`: default overlay seconds. `vol`: sound volume 0–100 (radio is ducked while it plays).
- `quiet_low`: `low` priority makes no sound during night hours. `ntfy`: optional ntfy.sh topic ("" = off).

### `PUT /api/config/notify`
`{"dur":10,"vol":70,"quiet_low":true,"ntfy":"meowbox-abc"}`, or `{"regen":true}` to create a new token
(the old one stops working at once). → same shape as GET.

### `POST /api/notify`
```
Authorization: Bearer q7Lw2xK9pR4tY8vZ
{"title":"Build xong","text":"esp32-playground OK","sound":"chime","priority":"normal","duration":10}
```
- `text` required (≤ 200 bytes), `title` optional (≤ 48 bytes).
- `sound`: `chime` | `alert` | `none` (default `chime`). `priority`: `low` | `normal` | `high` (default `normal`).
  `high` turns the screen on and sounds even at night. `duration`: seconds (default `dur`, 1–300).
- → `{"ok":true,"id":17}`. Queue holds 10; when full → `429 queue_full`.

### `GET /api/notify?text=...&token=...`
Short form for scripts/phones. Optional `title`, `sound`, `priority`, `duration` query params, URL-encoded.
→ same as POST.

### `POST /api/notify/audio`
Body = raw WAV or MP3 file (≤ 1 MB), `Content-Type: audio/wav` or `audio/mpeg`, Bearer token. Optional
`?title=&text=` to also show an overlay. → `{"ok":true,"id":18}`; too big → `413 too_large`.

### `GET /api/notify/history`
Last 20, newest first (RAM only):
```json
{"items":[{"id":17,"ts":1763791100,"title":"Build xong","text":"esp32-playground OK","sound":"chime","priority":"normal","src":"api"}]}
```
`src`: `api` | `pc` | `ntfy` | `audio`.

## PC agent

### `GET /api/config/pc`
```json
{"host":"192.168.1.10","port":8765,"auto":true,
 "st":{"on":true,"name":"DESKTOP-MEO","ip":"192.168.1.10","ver":"0.1.0","seen":1}}
```
- `host`/`port`: the agent's HTTP relay used for YouTube stations (`http://host:port/yt/stream?url=...`).
- `auto`: take host from the connected agent (`/ws/pc` peer IP or mDNS `_meowbox-pc._tcp`) instead of `host`.
- `st` is read-only: `on` = agent connected to `/ws/pc`, `seen` = seconds since last message.

### `PUT /api/config/pc`
`{"host":"192.168.1.10","port":8765,"auto":false}` → same shape as GET.

## System

### `POST /api/ota`
Body = raw firmware `.bin` (`Content-Type: application/octet-stream`, `Content-Length` required, max
5 505 024 bytes = size of `ota_1`). The firmware streams it into the inactive OTA slot (`esp_ota_write`), checks
the image, sets it as boot partition, replies, then reboots after ~1 s. The new image must call
`esp_ota_mark_app_valid_cancel_rollback()` after a healthy start, otherwise the bootloader rolls back.
→ `{"ok":true}`. Errors: `400 bad_image` (wrong magic `0xE9`/validation failed), `413 too_large`.

### `POST /api/reboot`
Body `{}` → `{"ok":true}`, reboots after ~1 s.

### `POST /api/factory_reset`
Body `{"confirm":true}` → `{"ok":true}`. Erases NVS (Wi-Fi, stations, alarms, cat, password, token) and
reboots into the SoftAP portal. Without `confirm:true` → `400 bad_value`.

## Battery

### `GET /api/battery` (session)
```json
{"pct":82,"raw":2330,"mv":4020,"chg":false,"rate":12.0,"eta":310,
 "cur":{"open":true,"start":1763791200,"min":80,"from":100},
 "sessions":[{"start":1763700000,"min":412,"from":100,"to":6,"mv_from":4180,"mv_to":3400,
              "bri":62,"play_min":180,"end":"empty","full_h":7.3}],
 "pts":[[1763791200,100.0,4180],[1763791260,99.8,4176]]}
```
- `pct` smoothed 0–100, `mv` calibrated battery voltage (assumes a 1:2 divider), `rate` discharge %/h over the last
  60 min, `eta` estimated minutes left (`-1` unknown or charging).
- `cur`: the running battery session (since unplugging). `sessions`: last 10 finished sessions, newest first;
  `end` = `plugged` | `empty` | `off`; `full_h` = projected 100→0 % runtime (only when ≥ 5 % was used).
- `pts`: up to 240 samples `[unix, pct, mv]` of the current (or last) session for a chart.

### `GET /api/battery/log.csv` (session)
Raw per-minute log while on battery: `ts,raw,mv,pct,brightness,volume,radio`.
